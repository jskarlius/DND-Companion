# Content packs

This directory contains distributable, versioned public content packs. Private
book content does not belong here or in the public repository.

## Bootstrap pack

`generated/open5e-srd-2024-bootstrap.json` is the reviewed Slice 6.75 public
bootstrap pack. It contains a deliberately limited Wizard data set, the Evoker
subclass, 110 Wizard spells through spell level 3, 17 feats, and the references
required by the sheet and future advancement work.

The pack is generated by `npm.cmd run content:bootstrap`, validated at runtime
against the content schemas, and read through the bundled content repository.
It is not inserted into IndexedDB: public packs are immutable application data
and are available offline as soon as the application loads.

Generated entities are kept in separate collections (`classes`, `subclasses`,
`features`, `resources`, `spells`, and `feats`). They refer to one another by
stable source-qualified IDs rather than copied display names or rules text.

## Storage boundary

```text
Generated public JSON ─┐
                       ├─ content repository ─→ application UI and rules code
Installed private packs┘
      (IndexedDB)

Characters and play state
      (IndexedDB)
```

Slice 8 will replace this bootstrap layout with the structured
`packs/srd-2024/` module directory, then extend the same repository to combine
that bundled data with
installed public and private packs stored in IndexedDB. Consumers should not
need to know which backing store supplied an entity.

## Provenance

The importer records Open5e's exact source label, currently "System Reference
Document 5.2" under document key `srd-2024`, together with CC BY 4.0
attribution. Do not claim the snapshot is verified SRD 5.2.1 until it has been
reconciled with the official 5.2.1 document.
